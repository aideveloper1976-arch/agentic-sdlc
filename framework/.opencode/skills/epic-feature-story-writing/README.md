# Epic Feature Story Writing Skill - Quickstart

## Purpose
Use this skill to convert validated scope into EPIC, Feature, and Story backlog items with strong acceptance criteria and traceability.

## Typical Usage

### 1) New backlog breakdown
```text
Use epic-feature-story-writing to break this feature idea into EPIC, Feature, and Story items.
Include testable acceptance criteria and edge cases.
```

### 2) Refine weak stories
```text
Use epic-feature-story-writing to rewrite these vague stories into buildable backlog items.
Flag open questions instead of guessing.
```

### 3) Readiness pass
```text
Use epic-feature-story-writing to check whether this feature has enough story detail for build.
List any backlog gaps.
```

## Expected Output
- EPIC summary
- Feature breakdown
- Story set with acceptance criteria
- Traceability and open questions
