## Task: Create EPIC to Story Breakdown

### Input
Validated product or feature scope

### Steps
1. Define the EPIC outcome and success metrics.
2. Break the EPIC into Features with scope boundaries.
3. Break Features into buildable Stories.
4. Add acceptance criteria, edge cases, and notes.
5. Return open questions and traceability links.

---

## Task: Rewrite Weak Backlog Items

### Input
Existing EPICs, Features, or Stories with insufficient detail

### Steps
1. Review the current wording and missing detail.
2. Rewrite the item into a testable format.
3. Add missing edge cases and acceptance criteria.
4. Flag unresolved scope questions.

---

## Task: Backlog Readiness Pass

### Input
Target EPIC, Feature, or Story set

### Steps
1. Check hierarchy completeness.
2. Check acceptance criteria quality.
3. Check coverage of UX, security, data, and test notes.
4. Return readiness gaps and exact fixes needed.
