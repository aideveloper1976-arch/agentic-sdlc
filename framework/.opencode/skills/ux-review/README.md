# UX Review Skill - Quickstart

## Purpose
Use this skill to review usability, accessibility, and flow quality for user-facing changes.

## Typical Usage

### 1) Page review
```text
Use ux-review on this page.
Return usability, accessibility, and clarity issues with evidence.
```

### 2) Flow review
```text
Use ux-review for this onboarding flow.
Identify friction points and blockers to task completion.
```

### 3) Form audit
```text
Use ux-review on this form flow.
Check labels, validation, error handling, and accessibility basics.
```

## Expected Output
- UX summary
- Findings by severity
- Accessibility notes
- Recommendation
