# Full Stack TypeScript Developer Skill - Quickstart

## Purpose
Use this skill to implement approved TypeScript scope with minimal, production-grade changes and explicit validation evidence.

## Typical Usage

### 1) Implement a story
```text
Use fullstack-typescript-developer for STORY-1806.
Implement the approved scope, update affected tests, and report validation results.
```

### 2) Fix a regression
```text
Use fullstack-typescript-developer to fix this regression.
Identify root cause, make the smallest safe code change, and add regression coverage.
```

### 3) Refactor safely
```text
Use fullstack-typescript-developer for this refactor.
Preserve behavior, keep contracts stable, and return the validation evidence.
```

## Expected Output
- Implementation summary
- Files changed with reasons
- Validation command/results
- Contract or schema impact
- Risks and follow-ups
