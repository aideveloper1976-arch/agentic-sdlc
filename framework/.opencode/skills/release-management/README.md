# Release Management Skill - Quickstart

## Purpose
Use this skill to prepare PR summaries, release notes, readiness evidence, and rollback-aware release decisions.

## Typical Usage

### 1) Prepare a PR
```text
Use release-management to prepare this PR summary.
Link story IDs, evidence, risk notes, and rollback considerations.
```

### 2) Release readiness pass
```text
Use release-management for a release readiness review.
Check traceability, validation evidence, risks, and blockers.
```

### 3) Generate release notes
```text
Use release-management to create release notes from this branch scope.
Include key changes, risks, and verification evidence.
```

## Expected Output
- PR or release summary
- Evidence checklist
- Risk and rollback notes
- Final readiness decision
