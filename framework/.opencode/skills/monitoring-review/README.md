# Monitoring Review Skill - Quickstart

## Purpose
Use this skill to review runtime health, logs, metrics, anomalies, and alerts after testing or release activity.

## Typical Usage

### 1) Post-release check
```text
Use monitoring-review after this deployment.
Check service health, logs, anomalies, and release impact.
```

### 2) Degraded service diagnosis
```text
Use monitoring-review for this degraded service.
Review health, logs, metrics, and alerts, then return the likely operational blockers.
```

### 3) Pre-release runtime gate
```text
Use monitoring-review before release sign-off.
Confirm the target services are healthy and no unresolved alerts block rollout.
```

## Expected Output
- Monitoring summary
- Health matrix
- Operational findings
- Pass or fail recommendation
