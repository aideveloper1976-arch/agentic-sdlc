# Traceability Validation Skill - Quickstart

## Purpose
Use this skill to validate whether a story, feature, or release has a complete lifecycle audit trail.

## Typical Usage

### 1) Story trace check
```text
Use traceability-validation for this story.
Check the full chain from research through test evidence and release readiness.
```

### 2) Release trace gate
```text
Use traceability-validation for this release candidate.
List missing links and whether the release is blocked.
```

### 3) Gap remediation pass
```text
Use traceability-validation to identify the missing artifacts for these stories.
Return the exact gaps and required fixes.
```

## Expected Output
- Traceability status
- Complete links
- Missing links and gaps
- Release readiness decision
