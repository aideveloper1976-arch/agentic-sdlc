# Browser Research Skill - Quickstart

## Purpose
Use this skill to gather evidence-backed market, competitor, pricing, and UX-pattern research from public sources.

## Typical Usage

### 1) Competitor scan
```text
Use browser-research for competitor analysis in this market.
Find comparable products, verify capabilities from real pages, and return source-backed gaps.
```

### 2) Pricing research
```text
Use browser-research to compare pricing and packaging across the top competitors.
Do not rely on snippets. Cite the pricing pages.
```

### 3) UX pattern review
```text
Use browser-research to study onboarding UX patterns for this product category.
Return recurring flow patterns with source evidence.
```

## Expected Output
- Research summary
- Source evidence table
- Competitor or pattern analysis
- Opportunities and gaps
