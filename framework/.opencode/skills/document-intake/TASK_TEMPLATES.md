## Task: Extract Candidate Requirements

### Input
Local source document

### Steps
1. Ingest the document.
2. Extract text and tables.
3. Extract candidate requirements with source locations.
4. Classify each item.
5. Flag contradictions and missing details.

---

## Task: Summarize Source Document

### Input
Local source document and summary goal

### Steps
1. Ingest the document.
2. Extract the most relevant sections.
3. Summarize the key points for the requested audience.
4. Include major risks, assumptions, and open questions.

---

## Task: Compare Multiple Documents

### Input
Two or more local documents

### Steps
1. Ingest each document.
2. Extract key requirements or decisions.
3. Compare for overlap, conflict, and gaps.
4. Return exact source-backed mismatches.
