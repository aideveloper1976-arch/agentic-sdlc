# Document Intake Skill - Quickstart

## Purpose
Use this skill to extract requirements, evidence, summaries, or comparison findings from local source documents.

## Typical Usage

### 1) Requirement extraction
```text
Use document-intake on this source file.
Extract candidate requirements, preserve source locations, and flag contradictions.
```

### 2) Executive summary
```text
Use document-intake to summarize this document for product planning.
Return key decisions, risks, and gaps.
```

### 3) Document comparison
```text
Use document-intake to compare these two source documents.
List overlaps, conflicts, and missing requirements.
```

## Expected Output
- Extracted requirements or summary
- Source references
- Contradictions and gaps
