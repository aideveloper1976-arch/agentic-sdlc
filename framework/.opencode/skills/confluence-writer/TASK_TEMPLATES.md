## Task: Update Existing Page

### Input
Confluence page target and content to apply

### Steps
1. Fetch the current page.
2. Identify the section to create or update.
3. Format content for readable Confluence output.
4. Apply the update.
5. Verify the page structure and embedded content.

---

## Task: Create New Technical Page

### Input
Space or parent page context and new content

### Steps
1. Confirm the destination and page title.
2. Organize the content into clear sections.
3. Add tables, diagrams, or embedded references where needed.
4. Publish the page and verify the final output.

---

## Task: Publish Structured Documentation

### Input
Technical content such as release notes, architecture notes, or API docs

### Steps
1. Normalize the content for Confluence readability.
2. Select the right rendering approach for each content type.
3. Update the target page.
4. Confirm links, diagrams, and rendered sections appear correctly.
