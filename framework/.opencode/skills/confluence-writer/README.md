# Confluence Writer Skill - Quickstart

## Purpose
Use this skill to create or update Confluence pages with technical content, structured documentation, diagrams, and embedded specs.

## Typical Usage

### 1) Update a technical page
```text
Use confluence-writer to update this Confluence page with the latest architecture summary and API notes.
Preserve page structure and validate the final content.
```

### 2) Publish a release note
```text
Use confluence-writer to publish this release summary into Confluence.
Use headings, tables, and links that read cleanly in the page.
```

### 3) Add embedded technical content
```text
Use confluence-writer to add this diagram and API spec to the target page.
Choose the right rendering approach and validate the page output.
```

## Expected Output
- Page target
- Summary of changes
- Embedded content details
- Validation notes
