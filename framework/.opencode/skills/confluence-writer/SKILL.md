# Confluence Writer

## Goal
Update Confluence pages cleanly and predictably, preserving structure while publishing technical content that is readable in Confluence.

## When to Use
- Publishing or updating technical documentation in Confluence.
- Adding architecture diagrams, API specs, or formatted knowledge-base content.
- Synchronizing project outputs into Confluence pages.

## Required Inputs
- Target Confluence page ID, URL, or space context.
- Content to publish or update.
- Any diagrams, tables, API specs, or attachments to embed.

## Workflow
1. Confirm the page target and whether the task is create vs update.
2. Structure the content for Confluence readability before writing.
3. Use the appropriate Confluence or Atlassian tool for page updates.
4. Preserve existing page intent and avoid damaging unrelated sections.
5. Verify the final page contains the expected sections, links, and embedded content.

## Required Output
## Page Target
## Summary of Changes
## Embedded Content
## Validation Notes

## Rules
- Prefer clear headings, concise paragraphs, and stable section structure.
- Preserve important existing content unless the task explicitly replaces it.
- Use supported Confluence formatting instead of raw markup that may not render.
- Keep diagrams and embedded API specs source-aligned and readable.
