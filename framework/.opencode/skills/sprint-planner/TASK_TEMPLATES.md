## Task: Build Sprint Plan

### Input
Candidate backlog items and sprint context

### Steps
1. Ask the mandatory context questions.
2. Score candidate stories.
3. Flag unhealthy or blocked stories.
4. Cut the sprint to realistic capacity.
5. Return the prioritized sprint recommendation.

---

## Task: Backlog Prioritization Pass

### Input
Backlog items and business priorities

### Steps
1. Confirm the primary business goal.
2. Score value, urgency, readiness, and dependency impact.
3. Group the items by recommended timing.
4. Return rationale for the prioritization.

---

## Task: Update Sprint Docs

### Input
Approved sprint plan

### Steps
1. Update `docs/10_sprint_plan/*` in the defined order.
2. Keep story IDs and sequencing consistent across files.
3. Reflect dependencies, risks, and deferred items.
