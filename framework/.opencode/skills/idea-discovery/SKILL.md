# Idea Discovery

## Goal
Define a clear problem, hypothesis, and business outcome before research and backlog work begin.

## System of Record
- Jira project: `$JIRA_PROJECT_KEY` for issue ownership and workflow state.
- Confluence space: `PROD` for idea brief documentation.

## When to Use
- New initiative intake.
- Pre-research discovery.
- Ambiguous requests that need business framing.

## Workflow
1. Define problem statement, target users, and current pain.
2. Capture assumptions, constraints, and key risks.
3. Define measurable success criteria.
4. Create or update a Jira Epic/discovery issue in the configured Jira project.
5. Create or update Confluence idea brief in `PROD`.
6. Add phase checkpoint in `docs/product/traceability/checkpoints`.

## Required Output
## Idea Brief Summary
## Jira Link
## Confluence Link
## Risks / Assumptions
## Next Phase Handoff

## Rules
- Do not skip success metrics.
- Do not mark discovery complete without Jira and Confluence links.
