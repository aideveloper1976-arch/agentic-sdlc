# Security policy

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button
on the Security tab of this repository, not in a public issue.

## Design notes

- No credentials live in this repo. Every server reads secrets from environment variables;
  see each server's `.env.example` and `framework/opencode.example.json` (`{env:VAR}` refs).
- `code-execution-mcp` only runs commands on an allowlist, blocks path-based execution and
  destructive patterns, and confines work to `CODE_EXECUTION_ALLOWED_DIR`.
- Dynamic agents generated by the framework default to `ask` for every shell command.
- CI runs gitleaks on every push and pull request.
